# Observatory

**Turning Uncertainty Into Knowledge**

Observatory is a research-first platform for studying prediction markets, forecasting, probability, statistics, economics, behavioral economics, market microstructure, NLP, and quantitative research.

This repository is not a trading bot and not a forecasting model. It is a knowledge base, learning platform, and research workspace designed to support disciplined inquiry under uncertainty.

## Vision
Build the foundation of a quantitative research institute: a place where ideas are structured, evidence is documented, and uncertainty is analyzed with rigor.

## Philosophy
- Research before implementation.
- Document assumptions explicitly.
- Prefer reproducible workflows and clear provenance.
- Separate learning artifacts from conclusions.

## Repository Structure
- `docs/` — project-level documentation
- `knowledge/` — domain knowledge base and learning materials
- `research/` — hypotheses, experiments, findings, and paper workflows
- `notebooks/` — organized notebook workspace (learning and exploration)
- `datasets/` — raw/processed/external data organization and lineage docs
- `resources/` — curated books, papers, courses, videos, and websites
- `meeting-notes/` — repeatable templates for research collaboration
- `ideas/` — structured templates for new proposals and hypotheses
- `roadmap/` — learning, research, and project progression plans
- `platform/` — application code workspace for ingestion, analytics, simulation, models, and tools

## Learning Approach
1. Follow staged domain progression in `roadmap/learning-roadmap.md`.
2. Capture foundational definitions in glossaries and concepts.
3. Maintain active study notes and resource curation per domain.

## Research Process
1. Define hypotheses and research questions.
2. Document methods and experiments with clear naming.
3. Record findings with confidence, limitations, and next steps.
4. Synthesize results into reusable knowledge artifacts.
